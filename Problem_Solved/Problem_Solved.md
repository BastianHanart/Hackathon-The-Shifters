# Eco Board

## Problème

Aujourd'hui, il est possible de récupérer des données écologiques seulement de manière manuelle. Ce processus est long, fastidieux et peut facilement être sujet à des erreurs ou des approximations.

## Solution proposée par Eco Board

Notre site récupère automatiquement les données écologiques depuis différentes API fiables. Ces informations sont ensuite affichées de manière claire et interactive sur notre site web, selon le territoire sélectionné :  

- **France entière**  
- **Région**  
- **Département**  
- **Ville**  

Grâce à Éco Board, l'accès aux données environnementales devient rapide, précis et facilement compréhensible pour tous.
